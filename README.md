# 台幣夜市遊戲街

台灣夜市小遊戲合集，單一個 `index.html`，直接用瀏覽器開就玩得。

## 遊戲

- **射氣球**（NT$50）：12 粒子彈，準星會晃。普通氣球 1 張獎券，金色★ 3 張。
- **投籃**（NT$50）：按住向後拉再放手。10 球，入波 1 張，空心 2 張。
- **套圈圈**（NT$50）：撳一下定方向，再撳一下定力度。前排 1、中排 2、後排 4，正中🎁 10 張。
- **開攤整嘢食**（免費）：75 秒內照客人張單揀材料出餐，賺台幣。
- **換獎品**：用獎券換公仔。

荷包由 NT$500 開始，進度存喺瀏覽器（localStorage）。
